# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository layout

This repo currently contains a single package: `client/`, a Next.js 16 (App Router) frontend for Gold BD, a digital gold buy/sell/hold platform for Bangladesh. There is **no backend in this repo** — `client/src/lib/api-client.ts` calls `/api/*` routes that are not implemented here (an earlier commit removed a `apps/web` + Prisma backend when the workspace was flattened to just `client`). Treat `src/types/index.ts` and the `src/lib/validations/*` Zod schemas as the source of truth for the API contract until a backend exists; don't invent server code unless asked.

## Architecture

**Routing / route groups** (`src/app`): `(auth)` holds login/register/verify-otp, `(dashboard)` holds the authenticated user app (buy-gold, sell-gold, wallet, transactions, kyc) behind `src/app/(dashboard)/layout.tsx`, and `admin/` is a separate authenticated section (rates, transactions, users) with its own layout. The marketing/landing page is `src/app/page.tsx` plus `src/components/landing/*`.

**Server state vs. client state — kept strictly separate:**
- Server data (wallet, gold rate, transactions, auth session) is owned by **TanStack Query**. Each domain has a `use-*.ts` hook in `src/hooks/` wrapping `useQuery`/`useMutation` around `src/lib/api-client.ts`'s `api.get/post/patch`. Mutations invalidate the relevant query keys on success (e.g. `useBuyGold` invalidates `["wallet"]` and `["transactions"]`) — follow this pattern for new mutations rather than manually refetching.
- Local/UI-only state (active landing tab, mobile menu open, locale) lives in **Redux Toolkit** (`src/store/`), a single `ui` slice. Do not put server data in Redux or client-only UI toggles in TanStack Query — `src/store/slices/ui-slice.ts` has the reasoning in its header comment.

**API client contract**: `src/lib/api-client.ts`'s `request()` expects every `/api/*` response to be the `ApiResponse<T>` envelope from `src/types/index.ts` (`{ success: true, data } | { success: false, error, fieldErrors? }`) and throws `ApiError` on `success: false`. Money/quantity fields cross the wire as decimal **strings** (`cashBalanceBDT`, `goldBalanceGrams`, `pricePerGramBDT`, etc.) to avoid float precision loss — format with the helpers in `src/lib/format.ts` (`formatBDT`, `formatGrams`, `mgToGrams`/`gramsToMg`) rather than doing arithmetic on them directly. Gold is stored/transmitted in integer milligrams.

**Forms**: `react-hook-form` + `@hookform/resolvers/zod`, validated against the schemas in `src/lib/validations/*.ts` (`auth.ts`, `gold.ts`, `kyc.ts`, `wallet.ts`). Add new form types there rather than inlining validation in components.

**i18n**: `src/lib/i18n/dictionary.ts` is a plain object keyed by `bn`/`en`; `useT()` (`src/lib/i18n/use-t.ts`) reads the active locale from the Redux `ui` slice and returns the whole tree for that locale. **This currently only covers the marketing/landing page** (`src/app/page.tsx` and `src/components/landing/**`) — the authenticated app (dashboard, forms, admin) is English-only. If you extend i18n to those areas, add matching keys to both `bn` and `en` in the dictionary.

**UI components** (`src/components/ui`): shadcn components using the `base-nova` style on top of `@base-ui/react` primitives (not Radix), configured in `client/components.json`. Variants are defined with `class-variance-authority`; use the `cn()` helper from `src/lib/utils.ts` for conditional classes. When adding shadcn components, match the existing aliasing (`@/components`, `@/lib`, `@/hooks`, `@/components/ui`).

**Styling**: Tailwind v4, config lives entirely in `src/app/globals.css` (no `tailwind.config`), which imports `shadcn/tailwind.css` and defines theme tokens via `@theme`/`@theme inline`. The landing/marketing page uses a fixed dark gold/ink brand palette (`--color-gold*`, `--color-ink*`, the `gold`/`gold-solid`/`gold-outline` button variants, `.btn-gold-shine`) that is intentionally *not* light/dark-mode aware; the authenticated app uses the neutral shadcn theme tokens instead, which do respond to light/dark mode.

**Fonts** (`src/app/layout.tsx`): Manrope (English UI/body), Noto Serif Bengali (Bangla fallback — loaded at 400 and 700 so bold Bangla text renders a real bold face), Playfair Display (serif display, hero eyebrow only), Geist Mono. Locale-aware text should rely on the `--font-sans` stack (Manrope → Noto Serif Bengali) rather than hardcoding a font family.
